# Super Mario Bros

A recreation of the NES classic built on the custom C++ engine.

## Building & Running

From the repository root:

```bash
cmake -B build
cmake --build build --target mario
./build/games/mario/mario
```

## Controls

| Key | Action |
|---|---|
| Arrow keys | Move |
| Space | Jump |
| Q | Quit |
