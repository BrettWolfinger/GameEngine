Detailed Description

template<typename T>
class Engine::Field< T >

A self-registering, implicitly-convertible config field.

Place Field<T> members inside a ConfigGroup subclass. Each member's constructor automatically registers it for TOML I/O and ImGui editing.

struct MyConfig : Engine::ConfigGroup {
Field<float> speed { this, "speed", 7.5f };
Field<int> lives { this, "lives", 3 };
};
